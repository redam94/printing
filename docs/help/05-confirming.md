Reply on the request in the portal, or straight to the e-mail about it. Either lands in the same place.

## To go ahead

Reply with one word:

```
CONFIRM
```

That is the only thing that starts a print. Nothing is printed while a request is waiting on you, however long it waits.

## To ask for changes

Say what should be different, in your own words. Be specific about which dimension or feature:

::: quote
"Looks good, but the slot needs to be 2 mm wider, and can the lid snap on instead of using screws?"
:::

A revised design and a new price come back, usually within a day. Revisions are numbered (r1, r2, r3) and the request keeps all of them, so you can compare.

::: warn "Looks good, but…" is a change, not a confirmation
A reply is read by a person, not a robot. Anything other than a plain confirmation is treated as a change request, and a `CONFIRM` that also asks a question gets an answer before anything goes on the printer. If you want it printed exactly as shown, say only CONFIRM.
:::

## To ask a question

Just ask, on the request. Questions do not count as changes and do not restart anything.

## To cancel

Say so on the request and it is closed. There is no charge for a request cancelled before you confirm, however many revisions it went through.

## After you confirm

1. The request moves back to **In Progress** and joins the print queue.
2. It is printed, cleaned up and checked against the measurements.
3. The request moves to **Done** and you get a message about picking it up or receiving it.

If something goes wrong during printing — a failed print, a flaw in the part — it is reprinted at no extra cost and you are told about the delay. You are not charged for our failures.
