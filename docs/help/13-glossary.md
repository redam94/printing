| Term | What it means |
|---|---|
| FDM | Fused deposition modelling: the printing method here. A nozzle lays down melted plastic in thin layers |
| Layer height | How thick each layer is. {printer.layer} here: fine enough for detail, quick enough to be affordable |
| Nozzle | The {printer.nozzle} opening the plastic comes out of. It sets the finest detail possible |
| Wall / perimeter | The solid outside skin of a part. Thicker walls mean a stronger part and a longer print |
| Infill | The honeycomb inside a part. {price.infill} is typical: strong enough, and far lighter than solid |
| Overhang | A face that leans out past about 45°. Steep overhangs need support underneath |
| Support | Sacrificial material printed under an overhang and broken off afterwards. It leaves a rougher surface |
| Bridge | A flat ceiling printed across a gap without support. Short bridges print cleanly |
| Bed | The glass or textured plate the part is printed on. The face touching it comes out smoothest |
| Build volume | The largest thing the printer can make in one piece: {printer.bed} |
| Slicer | The program that turns a 3D model into printer instructions, and gives the true print time |
| STL / 3MF / STEP | 3D file formats. STL and 3MF are meshes for printing; STEP is a CAD file that can still be edited |
| Watertight | A model with no holes or gaps in its surface. Only watertight models can be printed |
| Vase / spiral mode | Printing a hollow object as one continuous wall, with no seam. Fast, light, and very clean-looking |
| Heat-set insert | A brass threaded sleeve melted into the plastic, so a screw can go in and out many times |
| Living hinge | A thin section of plastic that bends instead of a pin-and-barrel hinge |
| Elephant foot | The slight bulge at the very bottom of a print. It is chamfered away in the design |
| Tolerance | How far a real measurement can stray from the drawing. About ±0.2 mm here |
| Clearance | Deliberate gap between two parts so they fit together: 0.3 mm a side for a sliding fit |
| Revision (r1, r2) | Each version of a quote. Yours keeps every revision, so you can compare |
